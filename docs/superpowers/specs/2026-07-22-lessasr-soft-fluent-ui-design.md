# LessASR Soft Fluent UI 设计

日期：2026-07-22

## 背景

现有主窗口直接使用 WPF 默认 `TabControl`、`DataGrid` 与基础控件样式，功能完整但缺少统一的视觉层级、组件语言和产品辨识度。用户确认采用已经评审过的可交互原型作为新界面方向，其信息密度与总体布局保持不变。

本次改造只重做 `LocalAsrClient.App` 的桌面界面，不改变 Core 层的听写状态机、ASR 编排、持久化规则和文本注入行为。

## 设计目标

- 让 LessASR 呈现为现代、安静、可信赖的 Windows 本地工具。
- 保留原型中适中的信息密度，不追求大面积空白或夸张装饰。
- 将模型状态、热键和今日使用概览集中到首页。
- 用列表与卡片替代传统表格和连续表单，强化阅读顺序。
- 主窗口、听写浮窗和连续听写窗口使用同一套颜色、字体、圆角和控件状态。
- 所有原有功能仍可到达，Debug 以“诊断”名称保留。

## 视觉语言

### 产品气质

设计方向为 **Soft Fluent × Typeless**：借鉴 Typeless 清晰的侧边导航、卡片层级、键帽提示和统计布局，同时使用 Fluent 风格图标与 Windows 原生字体，突出 LessASR 的本地、隐私和轻量属性。

### 颜色

- 应用背景：`#F5F6F8`
- 侧边栏背景：`#F0F1F3`
- 卡片背景：`#FFFFFF`
- 主文字：`#17181A`
- 次要文字：`#69707D`
- 弱化文字：`#9299A5`
- 分隔线：`#E4E6EA`
- 品牌色：`#4F6BED`
- 品牌浅色背景：`#EEF1FF`
- 成功色：`#159A72`
- 警告色：`#B7791F`
- 错误色：`#C2413A`

第一阶段只实现经过确认的浅色主题。所有颜色必须集中在资源字典中，不允许页面新增散落的硬编码色值。

### 字体

- 拉丁与数字：`Segoe UI Variable Text`
- 中文回退：`Microsoft YaHei UI`
- 页面标题：32px / SemiBold
- 区块标题：18px / SemiBold
- 正文：14px / Normal
- 辅助信息：12px / Normal
- 数字指标：28px / SemiBold，使用等宽数字特性能够支持时优先启用

### 几何与间距

- 以 4px 为最小单位，主要间距采用 8 / 12 / 16 / 24 / 32。
- 主卡片圆角 16px，小控件圆角 8–10px。
- 所有可点击按钮共享 10px 圆角、40px 最小高度和一致内边距；主按钮、次按钮、导航按钮与图标按钮只按语义调整颜色和布局，不再各自继承不同的基础模板。
- 内容卡片使用 1px 弱边框；阴影只用于主窗口浮层和听写浮窗。
- 默认窗口 1040×700，最小尺寸 800×560。
- 窗口缩小时指标卡片允许换行，文本必须换行而不是裁切。

## 信息架构

### 主导航

主导航位于左侧：

1. 首页
2. 历史记录
3. 使用统计
4. 模型
5. 设置
6. 诊断

前三项是日常使用入口，后三项放在分隔线下方。诊断页承接现有 Debug 功能，产品界面不再展示英文 `Debug`。

### 首页

- 页面标题“开口即写”。
- 本地服务状态徽标。
- 主引导卡：右 Ctrl 单句听写、F9 连续听写、Esc 取消。
- 主引导卡右侧只使用低对比度的麦克风与声波装饰，不使用实心按钮外观，不响应鼠标或键盘交互。
- 今日指标：听写次数、输入字数、录音时长。
- 最近 7 天输入趋势。
- 本地隐私说明。

首页指标只使用现有 `DailyStatsSnapshot` 可推导的数据，不引入虚构的“节省时间”算法。

### 历史记录

- 按今天、昨天和更早分组。
- 每条记录显示时间、文本、字数、复制与删除操作。
- 删除单条历史前显示与主界面一致的 Soft Fluent 二次确认窗口，包含目标文本摘要、默认取消和红色删除操作；确认后仅删除目标记录并立即刷新分组，取消时不更改数据。
- 二次确认窗口使用 `Dialogs/ConfirmationDialog` 通用组件，业务场景通过配置传入标题、说明、可选摘要、按钮文案、默认操作和普通 / 危险语义，不为后续删除场景重复创建窗口。
- 不使用 `DataGrid`，避免传统企业表格感。
- 保持最近 50 条的现有加载边界。

### 使用统计

- 顶部展示最近 30 天听写次数、文字量、录音总时长和平均每分钟输入字数；平均速度由同期字符总数除以录音总分钟数得到。
- 展示最近 7 天每日文字量趋势。
- 保留每日明细，但改为轻量列表而不是网格表。

### 模型

- 当前模型、服务状态、服务地址与路径置于信息卡。
- 启动、停止、重启、健康检查保持原有命令。
- 服务操作按钮等宽排列，启动服务使用主按钮，其余操作使用次按钮。
- 错误消息使用错误语义色，普通状态不使用强烈颜色。

### 设置

设置拆为以下卡片：

- 识别：首选语言。
- 模型服务：模型路径、服务路径、端口与线程数。
- 数据与隐私：固定数据路径、历史保留策略。
- 应用行为：启动预热、关闭到托盘。

保存按钮固定为页面最主要操作，保存反馈就近显示。

### 诊断

- 保留现有浮窗状态模拟按钮。
- 浮窗状态模拟按钮采用四列两行的等宽网格。
- 使用“诊断”而非 Debug 命名。
- 后续诊断能力继续追加到该页，不进入普通设置页。

## 高频窗口

### 听写浮窗

- 使用紧凑横向布局，圆角 16px。
- 状态图标、主消息与操作按钮按从左到右排列。
- 录音、识别中、成功、需操作和错误使用同一尺寸，避免状态切换时明显跳动。
- 仍保持不抢焦点、置顶和自动隐藏规则。

### 连续听写窗口

- 顶部显示标题、录制状态和提示信息。
- 每个分段使用编辑卡片；失败项使用弱错误背景。
- 底部操作栏保持可见，主要操作为“结束录制”。
- 不改变 Topmost、F9、右 Ctrl 和关窗持久化规则。

## 技术约束

- 保持 `net8.0-windows` 与 WPF，不迁移 WinUI 3。
- 使用 WPF UI 4.3.x 提供 Fluent Window、基础主题和图标能力；LessASR 的语义颜色与组件样式仍由本项目资源字典拥有。
- ViewModel 中新增的首页聚合和历史分组必须可独立测试。
- WPF/Win32 代码继续只存在于 `LocalAsrClient.App`。
- 不修改 `%USERPROFILE%\.lessasr\` 中的用户数据库。

## 可访问性与验收

- 所有图标按钮必须具有可读文本或 `AutomationProperties.Name`。
- 键盘可遍历导航、表单与主要操作，焦点状态清晰可见。
- 100%、125% 和 150% DPI 下不应出现裁切、重叠和模糊的位图图标。
- 800×560 最小窗口下所有功能仍可访问。
- Windows 10 与 Windows 11 均能运行；Mica 等效果只能作为有回退的增强。
- 现有单句听写、连续听写、托盘、模型管理、设置保存、历史复制和 Debug 模拟功能不得回归。
