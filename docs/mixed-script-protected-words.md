# 混合文字保护词表

LessASR 为中日韩文字与拉丁文字补空格时，将以下固定词整体视为中文，并保留词内部的连续写法。
当前收录 **35 个词，含简繁差异共 46 个词条**；大小写变体由匹配规则支持，不重复计数。

## 维护位置

实际生效的词表是 `src/LocalAsrClient.Core/Dictation/Data/MixedScriptProtectedWords.txt`，
UTF-8 编码，每行一词，以 `#` 开头的行是注释。构建时嵌入 Core 程序集，运行时加载一次。
它是随程序发布的内置词表，不是用户数据目录中的配置，不提供设置页编辑或热加载；
修改词表并重新构建后生效，通常无需修改匹配代码。此表独立于 Whisper 识别提示词汇表。

## 匹配边界

- 忽略拉丁字母大小写，但保留原文写法，如 `polo衫`、`卡拉ok`。
- 只匹配原本连续的词，不删除原有空格：`T 恤` 仍为 `T 恤`，`买 T恤` 仍为 `买 T恤`。
- 匹配后的整词按中文处理，两侧与中日韩文字、中文标点相邻时均不新增空格，
  例如 `买U盘和T恤`、`卡拉OK很好玩`、`（T恤）` 都保持原样。
- 匹配后的整词与词外拉丁文字相邻时仍补空格，例如 `T恤XL码` → `T恤 XL 码`，
  `Python阿Q` → `Python 阿Q`。这不改变下述匹配边界要求。
- 拉丁一端必须完整，不能命中更长拉丁串的一部分：`XA股` → `XA 股`、
  `卡拉OKR` → `卡拉 OKR`；相邻的数字、下划线或组合重音也会阻止该端匹配。
- 包含这些词的中文派生表达自然连续书写，例如 `T恤衫`、`K线图`、`X光片`、`阿Q正传`。
- 不使用“所有字母 + 卡 / 机 / 型”等通配规则，也不扩展为普通英文名词加中文的组合：
  `AI模型`、`Windows系统`、`Python代码` 仍分别补空格。
- 本批词表针对中文固定词；日文、韩文继续使用通用混排规则，未新增对应语言的固定词表。

## 选词依据

这些词是本产品为满足连续书写偏好整理的有限集合，不宣称它们在所有排版规范中都必须连写。
选取约定俗成的名称、缩略词组合与口语表达，不以数量为目标穷举临时组合。参考资料包括：

- [教育部：引导和规范外文缩略词使用的对策及建议](https://www.moe.gov.cn/s78/A19/s8358/s6169/201202/t20120202_129880.html)：列举阿Q、AA制、T恤、ATM机、IP卡等字母词。
- [商务印书馆：《现代汉语词典》字母词条目专家座谈会](https://www.cp.com.cn/Content/2013/11-10/1520480045.html)：讨论 B超、A型血、O型血等固定表达。
- [中国证监会：什么是A股、B股、H股？](https://www.csrc.gov.cn/gansu/c105495/c1306422/content.shtml)：对应股票名称的实际用例。
- [广州市越秀区政府网站服装附件](https://www.yuexiu.gov.cn/attachment/7/7859/7859185/10387083.pdf)：含 V领、POLO衫的服装名称。
- [中新网：广西“警花”手绘可爱漫画](https://www.chinanews.com.cn/shipin/cns/2023/01-07/news947797.shtml)：Q版、Q弹的实际用例。

其余项目按同类常见固定写法补充；本表不复制外部词典数据，也不依赖在线词典或新增运行时依赖。
