# LessASR 识别服务设计

## 目标

在保留现有本地 whisper.cpp 托管能力的同时，支持多套 OpenAI 兼容 Audio Transcriptions API 配置，并由用户在“服务”页选择唯一的当前识别服务。

## 服务模型

- 固定一个不可删除的“本地 Whisper”，由 LessASR 管理 `whisper-server` 生命周期。
- 允许添加任意数量的“远程 API”；这里的远程只表示 LessASR 不管理生命周期，地址可以位于本机、局域网或互联网。
- 同一时间只启用一个服务。`ActiveRemoteApiProfileId` 为空表示本地，否则指向当前远程配置。
- 旧用户和新安装默认使用本地服务。

## 远程配置

每份配置包含：唯一名称、固定类型“OpenAI 兼容 API”、完整转写端点、模型、可选 API Key、是否启用词汇表。

- 新配置不自动启用，词汇表默认关闭。
- 已有配置编辑时，Key 输入留空表示保留；“清除已保存 Key”显式删除。
- Key 使用 Windows CurrentUser DPAPI 保存，UI 不回填明文，运行时不弹出 Windows 密码提示。
- DPAPI 密文无法由当前 Windows 用户解密时显示“需要重新输入”，不把密文交给 ViewModel，也不降级为无认证请求。
- 已保存卡片出现字段或 Key 草稿时，测试与启用不可用；可以保存或放弃修改。清除已保存 Key 不提交其他草稿。
- 开启词汇表后，当前使用中的词汇表随请求作为 `prompt` 发送；关闭时不发送。

## 协议

远程请求向用户填写的完整端点单次 `POST multipart/form-data`：

- `file`
- `model`
- `response_format=json`
- 可选 `language`
- 可选 `prompt`

非空 Key 使用 Bearer，空 Key 不发送认证头。成功响应要求字符串 `text`，不支持平台专用扩展，不自动重试。

## 地址与传输安全

- 公网和主机名要求 HTTPS。
- HTTP 仅允许 `localhost`，以及 IPv4/IPv6 回环、私有、唯一本地或链路本地字面地址。
- 拒绝其他 scheme、用户信息、fragment、未指定、多播和广播地址。
- 不提供跳过 TLS 验证选项；HTTP 卡片明确展示未加密传输提示。

## 切换与生命周期

- 启用远程前先停止本地托管进程；停止失败则不改变选择。
- 切回本地只改变路由，不立即启动；仍按启动选项或听写时按需启动。
- 本地运行中保存配置只标记需要重启；“保存并重启”立即应用。
- 单句听写或连续听写忙碌时，禁止切换、编辑、删除、启停和重启；听写与服务变更通过共享活动租约串行化。当前启用的远程配置不可删除。
- 单句与连续听写共享同一个可切换后端，历史记录保存请求执行时快照的实际服务名和模型名；连续会话混用来源时标记为多个服务。

## 测试配置

- 每张卡独立手动测试，不改变当前服务。
- 远程测试发送短静音 WAV，并使用当前首选语言、认证和该配置的词汇表开关，可能产生费用；空 `text` 仍视为协议成功。
- 本地测试使用本地进程的就绪和健康检查；测试非当前本地服务时，临时启动后恢复停止状态。

## UI 信息架构

- 原“模型”导航改为“服务”。
- 本地模型、进程路径、端口、线程和启动选项从“设置”迁入本地服务卡。
- “设置”只保留识别语言、数据与隐私、应用行为。
- 首页状态和隐私文案根据当前服务动态显示；远程场景使用“音频发送至 API”，不使用“在线”或“服务商”。
