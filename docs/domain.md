# Domain

## 业务场景

为 Windows 用户提供接近 Typeless 的语音输入体验（产品名 **LessASR**）：托盘常驻、快捷键触发，可选择本地或 OpenAI 兼容远程识别，识别后优先直接写入当前焦点文本框。

## 核心角色

- **用户**：通过右 Alt 触发就地听写，通过 F9 打开独立听写，在主窗口查看状态、历史与统计。

## 核心对象

| 对象 | 说明 |
| --- | --- |
| InPlaceDictationOrchestrator | 一次从右 Alt 开始到最终注入、复制回退或取消的就地听写编排 |
| ContinuousDictationSession | 可连续分段的会话能力；就地听写与 F9 独立听写各使用一个实例 |
| ContinuousDictationSegment | 两种听写中的一段语音及其状态（WaitingInput / Transcribing / Completed / Failed） |
| AppSettings | 本地 whisper-server 参数、当前远程配置 ID、首选语言、保留策略等（存于固定数据目录下的 SQLite） |
| RemoteApiProfile | 一份命名的远程 API 配置：完整端点、模型、DPAPI 密文或空 Key、是否启用词汇表、可选代理地址 |
| VocabularyProfile | 一份命名的场景词汇表，包含有序词条文本和是否使用中的状态 |
| TextHistoryEntry | 可选保存的识别文本记录，包含识别时使用的模型配置名称与模型名 |
| DailyStatsSnapshot | 按“日期 + 模型配置名称”聚合的使用统计（不含识别原文） |
| AsrResult | ASR 返回的文本与耗时指标 |

## 就地听写状态

就地听写包含会话状态与段状态。会话从 `Idle` 进入录音；每次右 Ctrl 后，当前段进入 `Transcribing`，下一段立即进入 `WaitingInput` / 录音。最后按右 Alt 后停止继续录音，等待所有段完成，再进入一次 `Injecting`，最终回到 `Idle` 或进入复制结果态。

每段独立经历 `WaitingInput` → `Transcribing` → `Completed` / `Failed`。第一次 Esc 进入审阅态；审阅态再次 Esc 或关闭才取消整次会话。

详细交互与浮窗行为见 `docs/superpowers/specs/2026-08-18-in-place-and-independent-dictation-design.md`。

## 独立听写状态

独立听写使用专用窗口；每段独立经历 `WaitingInput` → `Transcribing` → `Completed` / `Failed`。会话另有“正在录制”状态：F9 进入，F9 结束 / Esc / “结束录制”/ 队列满 50 退出。

既有窗口与队列的历史设计见 `docs/superpowers/specs/2026-06-23-continuous-dictation-design.md`；现行命名和模式关系以 2026-08-18 规格为准。

## 关键规则

- 右 Alt 是 LessASR 专用的就地听写开关（键位定义于 `DictationHotkey`，与监听器实现解耦）：首次 `KeyDown` 立即触发并捕获目标窗口、输入控件与光标位置；录音中再次按下右 Alt，提交当前有效段、停止继续录音，等待所有段完成后一次性注入。目标缺失、失效或注入失败时显示合并正文供复制。
- 右 Ctrl 只在就地听写或独立听写正在录音时表示“下一句”：提交当前有效段进入 FIFO 队列，并立即开始下一段。空闲时不执行 LessASR 操作，也不吞键。
- 右 Alt 的按下、系统重复与松开事件均由 LessASR 完整拦截：首次按下触发一次，按住不重复触发，前台应用不会收到右 Alt，因此右 Alt 组合键与 AltGr 在 LessASR 运行期间不可用。右 Ctrl、F9 与 Esc 仍只在一次未参与组合键的完整按下并释放后执行，保持原始事件透传。
- 两种听写互斥：独立听写窗口打开时忽略右 Alt；就地听写尚未彻底结束时忽略 F9。
- 就地听写录音中第一次按 Esc 或点击关闭按钮，只丢弃当前未提交段并进入审阅态；已提交段继续识别。审阅态再次 Esc 或关闭才丢弃整次会话，不注入、不写历史。
- 录音时长不足 0.3 秒的段视为无效：直接移除，不进入识别，不显示失败占位，也不产生换行。
- 文本历史保留策略可配置（关闭 / 1 天 / 7 天 / 1 个月）。缩短策略时，保存前统计超出新期限的记录；存在待删除记录时向用户显示数量并要求确认，确认后立即清理，取消则不保存本次设置。历史清理不影响独立保存的使用统计。
- 历史记录详情显示识别时使用的模型配置名称；用户可以删除任意一条文本历史，删除前需要确认，确认后仅删除选中的记录且不可恢复。
- 统计数据不可关闭，最多保留 2 个月，不保存识别原文。
- 使用统计的 30 天汇总展示听写次数、输入字符数、录音总时长和平均输入速度；平均输入速度按“30 天输入字符总数 ÷ 30 天录音总分钟数”计算，录音时长缺失或为零时显示为 0。
- 使用统计的“每日明细”按“日期 + 模型配置名称”拆行；同一天使用多个配置时显示多行，30 天汇总与 7 天趋势仍跨配置合计。升级前无法区分来源的既有统计保留为“未区分模型”。
- 窗口关闭行为可配置（默认最小化到托盘；也可设为直接退出）。单击托盘图标或托盘菜单「打开窗口」时，主窗口恢复并显示到其他普通窗口前方；托盘菜单「退出程序」始终可退出并释放资源。
- MVP 不做 LLM 润色，ASR 原文直接注入（经空后处理器）。
- 可创建多份命名词汇表，但同一时间最多一份处于使用中，也允许全部停用。每份词汇表通过 Whisper `prompt` 提供识别软偏向：每行一个词或短语，最多 100 个去重后的非空词条，每项最多 30 个 Unicode 显示字符；支持混合语言，列表顶部优先级更高。保存或切换后从下一次 ASR 请求生效，不覆盖首选语言。
- 用户数据目录固定为 `%USERPROFILE%\.lessasr\`（`data/` 存 SQLite，`logs/` 存日志），不可配置。

### 识别服务

- 模型页始终有且只有一个本地 Whisper 配置；它固定在左侧列表第一项，由 LessASR 托管 whisper.cpp 的 `whisper-server` 生命周期，不能删除。远程配置排列在其后，左侧选择项、右侧编辑详情。
- 用户可创建多份远程 API 配置，但同一时间只能启用本地服务或其中一份远程配置。新远程配置默认不启用词汇表，也不会在保存后自动启用。
- 远程配置名称必须唯一；端点是完整的 Audio Transcriptions URL；模型不能为空；API Key 与代理地址均可为空。已有配置的 Key 输入框留空表示保留，只有显式“清除已保存 Key”才删除密文。
- 非空 API Key 以 Windows CurrentUser DPAPI 加密后保存，不要求用户在每次调用时输入 Windows 登录密码；UI 不回填明文。若密文来自其他电脑、其他 Windows 用户或已经损坏，卡片显示“需要重新输入”，并在替换或清除前禁止测试和启用。
- 模型配置与词汇表详情采用同一草稿规则：切换列表项时不弹窗、不自动保存，每份配置的未保存内容在当前会话内分别保留并就地提示；“保存”和“放弃修改”固定显示，无修改时禁用。当前配置有草稿时，依赖已保存配置的启动、测试或“启用”操作不可用。
- “清除已保存 Key”只改变已保存 Key，不会顺带提交远程卡片中的其他草稿。
- 远程配置单独决定是否发送当前词汇表。关闭时不发送 `prompt`；打开时发送当前使用中的词汇表。本地服务继续始终使用当前词汇表。
- 代理按远程配置独立生效，支持 HTTP、HTTPS、SOCKS4、SOCKS4a 与 SOCKS5；留空表示沿用 Windows/.NET 系统代理。配置代理后不绕过本机或局域网地址，手动测试与真实转写走同一代理。当前版本不支持认证代理，代理 URL 也不得包含账号密码。
- 切换到远程服务前必须先停止本地托管进程；停止失败则保持当前选择。切回本地不立即启动，仍遵循启动时加载选项或下次听写按需启动。
- 本地服务运行中保存会自动停止并重启进程，使路径、端口或线程参数立即生效；服务未运行时只保存配置。线程数留空表示使用系统推荐值，显式配置必须是大于 0 的整数。
- 就地听写或独立听写忙碌时，服务切换、编辑、删除、启停与重启均不可用；该约束由听写和服务变更共享的活动租约保证，而不是只依赖一次状态检查。当前启用的远程配置不可删除。
- 每个模型配置详情都有独立测试操作。远程测试发送一段短静音 WAV，并使用真实听写相同的首选语言、认证及该配置的词汇表开关，可能产生费用，不切换当前服务；空文本响应仍表示协议测试成功。远程请求失败后不自动重试。
- 远程地址通常必须为 HTTPS。HTTP 只允许 `localhost` 以及回环、私有、唯一本地和链路本地的字面 IP 地址；拒绝用户信息、片段、未指定、多播与广播地址。

### 共同分段规则

- 两种听写的识别队列均按 FIFO 串行消费，最大深度为 **50**；队列满时自动停止继续录音并提示用户，已经提交的段继续处理。
- `Completed` 段显示文本；`Failed` 段在原顺序位置显示“识别失败”及可选错误摘要，但不参与注入、复制或历史正文，也不产生空行。
- 每个进入识别流程的段分别写一次统计；取消和短于 0.3 秒的无效段不计入识别统计。取消会话不回滚已经写入的统计。
- 合并正文按列表顺序使用换行符（`\n`）连接非空 `Completed` 文本；历史使用各段实际转写时保存的服务/模型来源，多个来源混用时标记为“多个服务 / mixed”。

### 就地听写

- **右 Alt** 开始时捕获注入目标并显示紧凑波形浮窗；第一次按右 Ctrl 后，段落列表从录音行上方向上展开，底部波形行保持固定。
- 录音期间段落只读且浮窗不激活；审阅态允许编辑成功段，最终注入、复制和历史都使用编辑后的正文。
- 最后按右 Alt 后等待所有已提交段完成，只执行一次合并注入，并将整次非空正文保存为**一条** `TextHistoryEntry`。
- 没有可用目标或注入失败时进入复制结果态；若所有段都无效或失败，不注入空文本，也不写空历史。

### 独立听写

- **F9** 为独立听写专用热键：窗口不存在时创建、聚焦、置顶并进入录制状态；窗口已开且未录制时追加录制（不清空已有段）；窗口已开且正在录制时结束录制状态（当前有效段入队，不新建 `WaitingInput`）。
- **右 Ctrl** 在独立窗口正在录音时表示句子边界：结束当前段并入队，新建 `WaitingInput`，录音不中断。
- **关窗**（非“终止”）：收集所有 `Completed` 段当前文本（含用户编辑），合并后非空时写入一条历史；忽略其他状态且不等待队列排空。
- **“终止”**：立即停止录音，清空列表与队列，取消进行中的 ASR，不写文本历史。
- **Esc / “结束录制”**：仅结束录制状态；当前 `WaitingInput` 段不入队，窗口与已有项保留。
- 独立窗口中的识别结果只写入窗口内的段文本框，不注入外部焦点控件。

## 术语

- **whisper-server**：本地 HTTP ASR 服务进程。
- **本地 Whisper**：由 LessASR 托管 `whisper-server` 生命周期的固定识别服务。
- **远程 API**：由用户或提供方管理生命周期、使用 OpenAI Audio Transcriptions 请求/响应格式的服务；地址也可以位于本机或局域网。
- **注入（Injection）**：通过 Win32 控件消息、`SendInput` 或剪贴板粘贴回退将文本写入目标控件。
- **就地听写**：右 Alt 启动、在浮窗中连续分段、最终写入开始时捕获光标位置的听写方式。
- **独立听写**：F9 打开的专用 WPF 窗口，展示分段列表与终止 / 结束录制 / 复制操作，不与外部光标交互。
- **浮窗（Overlay）**：桌面底部承载就地听写波形、分段、审阅和复制回退状态的 WPF 窗口。
