# LessASR 识别服务设计

## 目标

在保留现有本地 whisper.cpp 托管能力的同时，支持多套 OpenAI 兼容 Audio Transcriptions API 配置，并由用户在“模型”页选择唯一的当前识别服务。

## 服务模型

- 固定一个不可删除的“本地 Whisper”，由 LessASR 管理 `whisper-server` 生命周期。
- 允许添加任意数量的“远程 API”；这里的远程只表示 LessASR 不管理生命周期，地址可以位于本机、局域网或互联网。
- 同一时间只启用一个服务。`ActiveRemoteApiProfileId` 为空表示本地，否则指向当前远程配置。
- 旧用户和新安装默认使用本地服务。

## 远程配置

每份配置包含：唯一名称、固定类型“OpenAI 兼容 API”、完整转写端点、模型、可选 API Key、可选代理服务器、是否启用词汇表。

- 新配置不自动启用，词汇表默认关闭。
- 已有配置编辑时，Key 输入留空表示保留；“清除已保存 Key”显式删除。
- API Key 输入框直接使用状态占位提示：未配置时显示“可为空”，已配置时显示基于系统 DPAPI 保存，无法解密时提示重新输入；输入框下方不再重复显示状态说明。
- Key 使用 Windows CurrentUser DPAPI 保存，UI 不回填明文，运行时不弹出 Windows 密码提示。
- DPAPI 密文无法由当前 Windows 用户解密时显示“需要重新输入”，不把密文交给 ViewModel，也不降级为无认证请求。
- 已保存卡片出现字段或 Key 草稿时，测试与启用不可用；切换模型会在当前会话内保留草稿，不弹出保存确认。清除已保存 Key 不提交其他草稿。
- 开启词汇表后，当前使用中的词汇表随请求作为 `prompt` 发送；关闭时不发送。
- 代理按配置独立启用，支持 HTTP、HTTPS、SOCKS4、SOCKS4a 和 SOCKS5。留空时沿用 Windows/.NET 系统代理；配置后不绕过本机或局域网地址，测试与真实请求走同一代理。
- 当前版本不支持认证代理，代理 URL 不得包含账号密码；如后续支持，凭据须作为密钥单独保护，不能随 URL 明文保存。

## 协议

远程请求向用户填写的完整端点单次 `POST multipart/form-data`：

- `file`
- `model`
- `response_format=json`
- 可选 `language`
- 可选 `prompt`

非空 Key 使用 Bearer，空 Key 不发送认证头。成功响应要求字符串 `text`，不支持平台专用扩展，不自动重试。

## 地址与传输安全

- 公网和主机名要求 HTTPS。
- HTTP 仅允许 `localhost`，以及 IPv4/IPv6 回环、私有、唯一本地或链路本地字面地址。
- 拒绝其他 scheme、用户信息、fragment、未指定、多播和广播地址。
- 不提供跳过 TLS 验证选项；HTTP 卡片明确展示未加密传输提示。

## 切换与生命周期

- 启用远程前先停止本地托管进程；停止失败则不改变选择。
- 切回本地只改变路由，不立即启动；仍按启动选项或听写时按需启动。
- 本地运行中保存配置会自动停止并重启服务以立即应用；服务未运行时只保存配置。线程数留空表示使用系统推荐值，显式配置必须是大于 0 的整数。
- 单句听写或连续听写忙碌时，禁止切换、编辑、删除、启停和重启；听写与服务变更通过共享活动租约串行化。当前启用的远程配置不可删除。
- 单句与连续听写共享同一个可切换后端，历史记录保存并展示请求执行时快照的实际模型配置名称和模型名；连续会话混用来源时标记为多个服务。
- 使用统计按“日期 + 模型配置名称”持久化；每日明细按配置拆行，跨配置的首页指标、30 天汇总和 7 天趋势保持合计展示。旧统计无法反推来源时标记为“未区分模型”。

## 测试配置

- 每个模型配置详情独立手动测试，不改变当前服务。
- 远程测试发送短静音 WAV，并使用当前首选语言、认证和该配置的词汇表开关，可能产生费用；空 `text` 仍视为协议成功。
- 本地测试使用本地进程的就绪和健康检查；测试非当前本地服务时，临时启动后恢复停止状态。

## UI 信息架构

- 主导航使用“模型”。页面采用与词汇表一致的左右布局：左侧是模型提供方列表，右侧是当前选中项的详情。
- 本地 Whisper 固定为列表第一项且不可删除；远程 API 依次列在其后并可删除。新增远程配置后直接选中其详情。
- 模型和词汇表的左侧列表都用“已启用”标记唯一生效项，与当前选中项的高亮含义分离。右侧详情右上角复用同一区域：已启用时显示“已启用”状态，未启用时显示“启用”按钮。
- 模型和词汇表详情的“启用”统一使用主按钮样式；配置卡片中的“启用”和“保存”均使用通用按钮内边距与自适应宽度，不设置模块专属最小宽度。
- 模型和词汇表的配置卡片底部操作均左对齐，并按主操作、普通辅助操作、危险操作的顺序从左到右排列。
- 模型和词汇表切换配置时均保留各自的会话内草稿并显示未保存提示，不使用切换确认弹窗。“保存”和“放弃修改”始终占位，只有存在草稿时才可用；保存按钮文案固定为“保存”。
- 本地详情底部只保留保存、启动、停止和测试操作；不提供独立的“保存并重启”或“恢复推荐值”按钮。
- 本地模型、进程路径、端口、线程和启动选项从“设置”迁入本地模型详情。
- “设置”只保留识别语言、数据与隐私、应用行为。
- 首页状态和隐私文案根据当前服务动态显示；远程场景使用“音频发送至 API”，不使用“在线”或“服务商”。
